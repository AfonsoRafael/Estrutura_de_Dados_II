# Estruturas de Dados II

Repositório destinado aos estudos, exercícios, atividades práticas e projetos desenvolvidos durante a disciplina de **Estruturas de Dados II**, do curso de Ciência da Computação.

A disciplina dá continuidade aos conceitos de estruturas de dados estudados anteriormente, avançando principalmente para estruturas de dados não lineares, com foco em grafos, árvores e algoritmos de busca.

---

## Sobre a Disciplina

**Curso:** Ciência da Computação  
**Disciplina:** Estruturas de Dados II  
**Semestre:** 4º  
**Carga horária:** 60 horas  
**Carga horária semanal:** 3 horas  
**Linguagem principal:** C

A disciplina tem como objetivo aprofundar os conhecimentos sobre estruturas de dados e sua aplicação prática no desenvolvimento de algoritmos e sistemas computacionais.

---

# Conteúdos

## Unidade I — Revisão das Estruturas de Dados Básicas

Nesta primeira etapa serão revisados conceitos fundamentais necessários para o desenvolvimento das estruturas mais avançadas.

### Conteúdos

- Tipos de dados primitivos
- Representação de dados na memória
- Arrays unidimensionais
- Matrizes
- Structs
- Organização dos dados na memória
- Ponteiros e endereçamento

---

## Unidade II — Estruturas de Dados Complexas

Continuação dos estudos sobre estruturas lineares e gerenciamento de memória.

### Conteúdos

- Ponteiros
- Operações com endereços de memória
- Filas
- Pilhas
- Listas estáticas
- Listas dinâmicas
- Listas ordenadas
- Listas encadeadas
- Alocação dinâmica de memória
- Manipulação de nós

---

## Unidade III — Grafos

Introdução às estruturas de dados não lineares por meio dos grafos.

### Conteúdos

- Conceito de grafo
- Vértices
- Arestas
- Representação de grafos
- Implementação de grafos
- Busca em largura
- BFS — Breadth-First Search
- Busca em profundidade
- DFS — Depth-First Search
- Construção de algoritmos utilizando grafos

---

## Unidade IV — Árvores

Estudo das estruturas hierárquicas e de suas principais aplicações.

### Conteúdos

- Árvores
- Árvores binárias
- Nós
- Raiz
- Folhas
- Arestas
- Subárvores
- Altura
- Profundidade
- Grau de um nó
- Caminhos
- Níveis
- Árvores balanceadas
- Heap

---
